Schematic capture (EDA)

Drag components onto the canvas, wire pin-to-pin with automatic nets, and catch mistakes with live ERC.

Real-time simulation

An analog (MNA) solver computes node voltages and currents; LEDs glow, meters read, buttons respond.

Run real firmware

Write Arduino code and run it on an emulated ATmega328P — actual compiled AVR, driving your circuit.
